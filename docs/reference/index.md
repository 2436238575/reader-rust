## 与教程的区别

- 想**写书源** → 看 [书源开发文档](/book-source/)，那里是分篇教程与示例
- 想**重新实现一套兼容的解析器**、或改造 `src/parser/` → 看本目录的兼容规格
- 想了解**当前代码怎么组织** → 看 [架构说明](/maintainers/architecture)

兼容规格采用 RFC 风格的 MUST / SHOULD / MAY 措辞：

- **MUST** —— 必须实现，否则大量书源不兼容
- **SHOULD** —— 建议实现，缺失会影响部分书源或边界行为
- **MAY** —— 可选能力，缺失时应明确降级
