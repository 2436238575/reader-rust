# 归档文档

本目录存放**历史快照**：某个时间点的设计方案、实施计划与进度记录。

::: warning 这些文档不代表当前实现
归档文档保留下来是为了追溯「当时为什么这么设计」，而不是描述现在是什么样。里面的字段名、接口路径、组件结构、任务清单都可能已经和代码不一致。

**请勿据此开发。** 需要当前行为时，请查：

- [书源开发文档](/book-source/) —— 书源规则
- [API 参考](/api/) —— `/reader3/*` 接口
- [指南](/guide/) —— 部署、配置、功能
- 仓库根目录的 `AGENTS.md`（不在本文档站内）—— 工程事实权威
:::

## 为什么保留

本项目把文档视为开发目标的一部分。曾计划、曾设计、但当前未实现的内容**不会被删掉**，而是标注状态后保留 —— 便于后来者判断某项能力是「没做」还是「做过后移除了」。

同样的原则也适用于面向用户的文档：若某功能只在文档中描述而代码尚未实现，会以如下形式标注，而不是删除条目：

```text
> **未实现**：<说明>（依据：<代码位置>）
```
