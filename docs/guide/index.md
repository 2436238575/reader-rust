# 简介

Reader-Rust 是 [阅读3.0](https://github.com/hectorqin/reader) 的 Rust 重写版 —— 一个**书源阅读 API 服务端**，附带一套 Vue 3 Web 界面。

它的职责是：管理书源、抓取上游站点、按书源规则解析出书籍与章节内容、维护书架与用户数据，并把这些能力通过 `/reader3/*` 接口暴露给前端或其他客户端。

> 本项目只提供书源管理、解析、阅读与缓存的技术能力，**不内置、不存储、不分发**任何受版权保护的书籍内容。

## 主要特性

- **高性能**：Rust + axum + tokio 异步实现，内存安全，并发抓取能力强
- **灵活书源**：CSS 选择器、JSONPath、XPath、正则、JavaScript 五种解析方式
- **规则引擎**：自动识别内容类型并匹配解析规则，完整兼容阅读3.0 的书源语法
- **数据持久化**：SQLite 存书源与用户数据，章节正文以文件形式缓存
- **多用户**：账号体系、书架上限控制、邀请码注册、多端登录
- **配套 Web 界面**：Vue 3 + TypeScript + Pinia，支持亮/暗主题、简繁转换、TTS 与 PWA 离线阅读

## 架构概览

```
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│  Web 前端     │─────→│   API 层      │─────→│   服务层      │
│ (Vue 3 + Vite)│      │   (axum)     │      │  (业务编排)   │
└──────────────┘      └──────────────┘      └───────┬──────┘
                                                    │
                          ┌─────────────────────────┼─────────────────────────┐
                          ↓                         ↓                         ↓
                    ┌───────────┐            ┌─────────────┐           ┌───────────┐
                    │  抓取层    │            │   解析层     │           │  存储层    │
                    │ (reqwest) │            │ (规则引擎)   │           │ (SQLite)  │
                    └───────────┘            └─────────────┘           └───────────┘
```

一次请求的完整链路：

```
HTTP 请求 → 路由匹配 → 提取鉴权与参数 → 业务编排 → 抓取上游页面 → 规则解析 → 包装 JSON 返回
```

## 模块结构

| 目录 | 职责 |
|------|------|
| `src/api/` | 路由定义与 HTTP 处理（axum），业务路由统一挂在 `/reader3` 下 |
| `src/service/` | 业务编排：缓存命中判断、书源选择、书架与用户逻辑 |
| `src/parser/` | 规则解析引擎，含组合规则拆分与 JS 求值 |
| `src/crawler/` | 基于 reqwest 的 HTTP 抓取与 URL 占位符处理 |
| `src/model/` | `BookSource` 等数据结构 |
| `src/storage/` | SQLite（sqlx）迁移与文件缓存 |
| `src/app/` | 配置加载与启动引导 |
| `frontend/` | Vue 3 + TypeScript + Vite + Pinia 前端 |
| `docs/` | 本 VitePress 文档站 |
