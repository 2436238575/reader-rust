## 系统简介

Reader-Rust 是一个用 Rust 实现的书源阅读服务器，自带 Web 前端界面，支持多书源搜索、在线阅读与书架管理。

### 主要特性

- **多书源支持**：导入多种书源，实现全网书籍搜索
- **在线阅读**：章节阅读、字体调节、主题切换、听书
- **书架管理**：收藏书籍，支持分组与排序
- **进度保存**：自动记录阅读位置
- **AI 资料**：按已读章节整理世界观、角色与地图
- **PWA 支持**：可安装为桌面应用，支持离线阅读

## 安装 PWA 应用

### 什么是 PWA

渐进式 Web 应用（PWA）是用 Web 技术构建、可从同一份代码库安装到各类设备的应用。安装后具有接近原生应用的体验，同时仍可在浏览器中像网站一样使用。

### 安装

点击右上角头像进入设置，找到「应用 → 安装到主屏幕」。部分浏览器与 iOS 不支持该方式，可改用浏览器自带的「添加到主屏幕」。

## 登录与账户

### 登录

1. 点击页面右上角的「登录」按钮
2. 在弹窗中输入用户名和密码

![登录界面](../images/index/homepage.png)

3. 点击「登录」完成

登录凭证会保存在本地，服务端支持**同一账号多端登录**。

### 登录后的界面

登录成功后默认进入书架页。右上角显示当前用户名，点击可进入设置；旁边的按钮切换日间 / 夜间模式。

![登录后界面](../images/index/bookshelf/shelf.png)
![设置界面](../images/index/settings.png)

## 书架管理

### 查看书架

点击左侧导航栏的「书架」图标，查看已添加的书籍。

- **书籍展示**：卡片形式显示封面与基本信息，点击封面查看详情
- **分组管理**：创建分组，分类存放书籍
- **书籍排序**：默认按最近阅读排序，可长按拖动卡片改变顺序
- **缓存管理**：管理浏览器缓存与服务器缓存

### 添加到书架

在搜索结果或书海中点击「加入书架」。

### 管理书架

- **编辑模式**：点击编辑按钮进入批量管理模式
- **删除书籍**：选择书籍后点击删除
- **移动分组**：将书籍移动到不同分组

### 缓存管理

- **缓存到服务器 / 浏览器**：可选缓存 50 章、100 章或全部
- **删除缓存**：从服务器 / 浏览器删除缓存

![缓存管理界面](../images/index/bookshelf/bookcache.png)

## 搜索书籍

### 使用搜索

Reader-Rust 支持多书源同时搜索，结果边到边显示。

1. 在首页或书架页面找到搜索框
2. 输入书名、作者名或关键词
3. 按回车或点击搜索按钮

![搜索结果](../images/index/search/search-results.png)

### 搜索结果说明

搜索结果来自多个书源，书名与作者相同的条目会合并为一本书的多个书源：

- **书名**：书籍标题
- **作者**：作者名称
- **操作**：加入书架或直接阅读

### 搜索技巧

- 使用精确书名可获得更准确的结果
- 支持作者名搜索（取决于书源是否支持）
- 结果实时返回，不同书源的结果会陆续出现

## 书源管理

### 什么是书源

书源是 Reader-Rust 用来搜索和获取书籍内容的配置。添加不同书源即可扩展可搜索的书籍范围。

![书源管理](../images/index/booksource/booksource.png)

### 打开书源管理

点击左侧导航栏的「书源」按钮。

### 添加书源

**从 URL 导入**

1. 获取书源 JSON 文件的 URL
2. 在书源管理界面点击「导入」
3. 选择「从网络导入」
4. 粘贴 URL 并确认

**本地导入**

1. 准备好书源 JSON 文件
2. 在书源管理界面点击「导入」
3. 选择「从文件导入」
4. 选择本地文件

### 管理书源

- **启用 / 禁用**：控制书源是否参与搜索
- **分组筛选**：按分组查看书源
- **删除书源**：移除不需要的书源
- **编辑书源**：在线编辑 JSON。需要登录的书源，先点编辑，再点书源登录

## 阅读功能

### 开始阅读

1. 在书架中点击想要阅读的书籍
2. 或在搜索结果、书海中点击书籍

### 阅读界面

![阅读界面](../images/reader/image.png)

#### 基本操作

- **翻页**：点击屏幕左右两侧或滑动
- **目录**：点击左侧按钮打开章节目录

## 阅读设置

点击屏幕中央或设置按钮，可调整以下内容。

### 字体设置

- **字体大小**：A- / A+ 调节
- **字体粗细**：- / + 调节，或直接输入数字

### 段落设置

- **段落行高**：- / + 调节
- **段落间距**：- / + 调节

### 主题设置

- **亮色模式**：白底黑字
- **暗色模式**：黑底白字

### 阅读宽度

调节阅读区域宽度，以适应不同屏幕尺寸。

### 翻页方式

- 上下滑动
- 左右滑动
- 上下滚动（无缝衔接下一章）
- 上下滚动 2（隐藏已读章节）

## 高级功能

### 书签管理

- **添加书签**：在阅读位置添加标记
- **查看书签**：列出全部书签位置
- **删除书签**：管理已添加的书签

### 章节导航

- 上一章 / 下一章快速切换
- 目录树形展示，支持搜索
- 快速跳转到指定章节

### 自动阅读

- 按段落或按像素移动
- 可调节移动速度

### 内容过滤

支持自定义替换规则（净化规则）。添加方式：

1. 打开选择文字的操作按钮，选中文字后按书添加规则，或按书源添加规则
2. 进入「设置 → 管理净化规则 → 新增规则」

另支持**简繁体转换**。

### 听书功能

- 支持文字转语音
- 可使用浏览器自带 TTS，也可配置 OpenAI 格式的 Speech API
  - 浏览器 TTS 推荐 Edge —— 它接入了 Azure 接口，效果最佳
- 可调节语速、音色
- 支持定时关闭

## AI 资料

书架中的普通书籍会显示 **AI 资料** 入口。AI 资料按已读章节整理世界观、重要角色、人物关系和地点地图，适合长篇阅读时回顾设定。

![AI 资料总览](../images/index/ai-book/overview.png)

基本流程：

1. 将书籍加入书架
2. 在书籍卡片、书籍详情或阅读页打开 **AI 资料**
3. 在设置页配置自己的 OpenAI 兼容模型，或使用管理员提供的后端模型配置
4. 点击 **更新到当前进度** 生成资料
5. 打开 **自动更新** 后，后续读完章节会自动尝试更新

地图页支持图片地图；图片模型不可用时降级显示关系图。

![AI 资料地图](../images/index/ai-book/map.png)

详细配置、权限与接口说明见 [AI 资料](./ai-book)。

## 常见问题

### 无法登录怎么办？

1. 检查用户名和密码是否正确
2. 确认服务器是否正常运行（`curl http://<host>:<port>/health`）
3. 检查网络连接

若服务器开启了 `SECURE`，浏览器访问时还需带上正确的 `secureKey` 参数。

### 搜索不到书籍？

1. 确认已添加书源，且书源处于启用状态
2. 换一个关键词再试
3. 用书源管理里的测试 / 调试功能确认该书源当前是否可用

### 阅读时加载慢？

1. 检查网络连接
2. 尝试在书源切换中换一个更快的源
3. 清理缓存后重试

### 如何备份数据？

1. 使用设置中的「服务端备份」功能
2. 配置 WebDAV 同步
3. 直接备份服务器上的 `storage/` 目录（数据库与章节缓存都在这里）

## 技术信息

- **前端**：Vue 3 + TypeScript + Vite + Pinia
- **后端**：Rust + axum + tokio + sqlx
- **数据库**：SQLite
- **支持的解析方式**：CSS 选择器、JSONPath、XPath、正则、JavaScript
