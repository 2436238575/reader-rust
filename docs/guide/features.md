# 功能特性

以下是当前版本已实现的功能清单。仓库里**只有一套前端** —— `frontend/`（Vue 3 + TypeScript + Vite + Pinia）。

::: details 关于旧版前端
本项目早期曾有一个 `web/` 目录（Vue 2 + Element UI 的旧前端），已在后续版本中移除。现在只需构建 `frontend/`，其产物 `frontend/dist/` 就是后端默认托管的 `WEB_ROOT`。
:::

## 前端界面

### 书架

- 书架首页，分组标签页（全部 / 未分组 / 自定义分组），响应式网格布局
- 书籍卡片显示封面、书名、作者与未读角标
- 编辑模式支持批量选择与删除
- 书籍详情弹窗：目录加载、缓存信息、更换数据源
- 书籍分组管理：新建分组、批量移动、拖动排序

### 搜索

- SSE 实时多源搜索，搜索结果边到边显示
- 搜索范围可切换：全部书源 / 按分组 / 单个书源
- 结果显示书源信息与最新章节
- 搜索结果一键加入书架

### 阅读

- 全屏阅读区，目录抽屉（高亮当前章节）
- 字体大小与行距调节
- 阅读进度自动保存与恢复
- 简繁转换（`opencc-js`）
- 上一章 / 下一章导航
- 章节内全文搜索
- 正文替换规则（去广告等）
- 书签的添加、查看与删除
- 阅读页内切换书源
- 自动翻页（像素滚动，速度可调）与翻页点击区域可视化
- TTS 语音朗读

### 阅读设置

- 主题（亮色 / 暗色）、字体、排版与翻页方式
- 「章节配图」开关：整体隐藏/显示正文里的插图（默认显示）
- 右侧浮动工具栏：书签、刷新、自动翻页、听书、夜间模式

### 探索（书海）

- 按书源分类浏览书籍
- 滚动加载更多，可直接加入书架

### 最近阅读

- 最近阅读列表，支持搜索与删除条目

### 设置

- 登录 / 注销，用户信息展示
- 亮色 / 暗色主题切换
- 阅读统计（累计时长、书籍数、章节数）
- 书架缓存刷新
- 服务端备份管理（WebDAV）

### AI 资料

- 用 OpenAI 兼容模型整理已读章节的世界观、角色、关系与地点地图
- 支持自动更新；地图渲染失败时降级为关系图

详见 [AI 资料](./ai-book)。

### PWA

- 离线访问（缓存最近阅读的章节）
- 安装到主屏幕
- Service Worker 更新提示
- 离线兜底页面

相关文件：`frontend/public/sw.js`、`frontend/public/site.webmanifest`、`frontend/src/utils/pwa.ts`

## 后端能力

### 书源管理

- 书源列表、查询单条书源、设置默认书源
- 新增 / 编辑 / 删除书源，支持批量保存、批量删除、清空全部
- 本地文件导入与远程 URL 导入书源
- 书源登录（`loginBookSource`）
- 获取探索分类（`getExploreKinds`）
- 无效书源检测与一键清理
- 书源测试与实时调试（SSE）

### 搜索与发现

- 关键词搜索单个书源
- 多书源并发搜索（SSE 实时返回各源结果）
- 获取可用书源（依次尝试，SSE 流式返回）
- 按分类探索书源（`exploreBook`）

### 书架与书籍

- 书架列表、书籍详情（含缓存信息）
- 新增 / 删除书籍，批量保存与批量删除
- 更换书籍数据源
- 书籍分组：保存分组、调整顺序、删除分组、批量加入 / 移出分组
- 上传本地 TXT 与 EPUB 书籍
- 保存阅读进度
- 书籍封面代理

### 章节与缓存

- 拉取章节目录（`getChapterList`）
- 获取章节正文（`getBookContent`）
- 清除书籍缓存
- 缓存整本书（SSE 实时进度）

### 评论（章评 / 段评）

书源声明了评论规则时，阅读页会显示段落旁的段评气泡与正文末尾的「本章评论」入口。

- 段评概览（`getParaCommentIndex`）：哪些段落有评论、各多少条
- 单段段评（`getParaComments`）
- 章评（`getChapterComments`）
- 评论缓存保留 7 天 TTL（`REVIEW_CACHE_TTL_SECS`），并可按 `kind: review` 清理

规则写法见 [书源规则参考 · 评论规则](../reference/book-source-rules#评论规则)，接口见 [评论 API](../api/review)。

### 章节配图

阅读页会把章节插图渲染在正文里，点图可放大查看。

- 正文 HTML 里内嵌的 `<img>` 直接渲染，不需要书源额外配置（漫画/图集源、出版书插图都走这条）
- 书源也可以声明独立的配图接口（`ruleContentImage`），由接口给出图片地址、说明与插入位置
- 图片按书源给的位置插在对应段前，位置缺失时排在章末
- 配图不缓存：图片地址普遍带时效签名，缓存下来过一阵就是死链

规则写法见 [书源规则参考 · 章节配图](../reference/book-source-rules#_17-7-章节配图规则-rulecontentimage)，
接口见 [章节 API · 获取章节配图](../api/chapter#获取章节配图)。

### 书签

- 获取书签列表，新增书签，批量操作，单条 / 批量删除

### 替换规则

- 替换规则的列表、新增、批量保存与删除

### 账号（单用户）

- 登录 / 登出，获取当前用户信息
- 修改密码（旧令牌全部失效，当前设备换发新令牌）
- 用户个性化配置的读写
- 多端登录（token 持久化，详见下节）
- 版本更新检查与忽略

### 备份与文件

- WebDAV 文件列表、下载、上传与删除
- 通用文件上传与删除
- TXT 目录规则的默认值查询

## 技术特点

- **高性能**：Rust 异步实现，多书源并发抓取
- **多种解析器**：CSS 选择器、JSONPath、XPath、正则、JavaScript
- **自动识别**：规则引擎按内容类型自动选择解析方式
- **数据持久化**：SQLite 存书源与用户数据，章节正文以文件形式缓存（MD5 命名）。缓存不按时间过期，可通过缓存管理接口按用户/书籍/类型清理
- **统一响应**：所有接口以 `{ isSuccess, errorMsg, data }` 包装

## 请求流程

```
用户请求 → API 路由 → Handler → Service → Crawler / Parser → 包装 JSON 返回
```
